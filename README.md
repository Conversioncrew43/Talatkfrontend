## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Booking API

The booking flow uses the Express API in `../backend`. Start that service with `npm run dev` from the backend directory; it requires a valid `MONGODB_URI` and `JWT_SECRET`. The local frontend defaults to `http://127.0.0.1:4000` because the API binds to IPv4. For a deployed frontend, set `NEXT_PUBLIC_API_URL` to the public backend origin before building. Email OTP and Razorpay checkout also require the corresponding backend SMTP and Razorpay environment variables.

You can start editing the page by modifying `app/page.js`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
